## The band

**The Soldering Irons** — hit single 'Hot Stuff (Literally)' melted the stage, the fans, and the bassist.

Four robots, one soldering iron each, zero fire extinguishers. Their debut
gig ended with the stage in a puddle, the front row slightly singed, and the
bassist — Sparky — melted mid-solo. The crowd called it "the hottest show of
the year" and meant it literally.

## Lineup

- **Vox-9** — lead vocals (voice box rated to 400°C)
- **Ampere** — lead guitar (strings replaced after every show)
- **Rusty** — drums (kept away from the sprinkler system)
- **Sparky** — bass (melted; position currently open)

## Run it

```sh
python3 main.py
```

It prints the band's one-line entry and writes it to `/output/entry.txt`.
